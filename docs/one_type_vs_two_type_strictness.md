# Closing the one-type/two-type 4-cycle question

This note closes the remaining comparison

\[
\Delta+\square_2 \stackrel{?}{=} \Delta+\square_1.
\]

The answer is negative:

\[
\boxed{\Delta+\square_2 \prec \Delta+\square_1.}
\]

The separation is witnessed by an explicit pair of ordinary finite, simple,
unlabelled graphs on 80 vertices and 160 edges.  The pair is a parity-square
construction.  It is the edge-message-passing analogue of the familiar fact that
pairwise marginals do not determine a parity distribution.

The proof has three parts.

1.  \(\Delta+\square_1\) always refines \(\Delta+\square_2\).
2.  A parity pair \(G_0,G_1\) is constructed.
3.  \(G_0\equiv_{\Delta+\square_2}G_1\), but
    \(G_0\not\equiv_{\Delta+\square_1}G_1\).

The smallest pair is generated by

```bash
python experiments/check_one_type_two_type.py --d 1 --print-graph6
```

---

## 1. The two 4-cycle aggregations

All graphs are finite, simple, undirected, and loopless.  For a graph \(G\),
write

\[
\vec E(G)=\{(u,v):uv\in E(G)\}
\]

for the ordered edges.  At round \(t\), an ordered edge \((u,v)\) has color
\(\chi_t(u,v)\).  All modes considered here include old color and left/right
incidence:

\[
\chi_t(u,v),
\qquad
\multiset{\chi_t(u,x):x\in N(u)},
\qquad
\multiset{\chi_t(v,z):z\in N(v)}.
\]

The triangle term is

\[
T_t(u,v)=
\multiset{(\chi_t(u,y),\chi_t(v,y)):y\in N(u)\cap N(v)}.
\]

A simple oriented 4-cycle witness for \((u,v)\) is a pair \((y,w)\) such that
\(u,y,w,v\) are pairwise distinct and

\[
uy,yw,wv,vu\in E(G).
\]

Equivalently, \(u-y-w-v-u\) is a non-induced 4-cycle using the root edge
\(v-u\).  Chords are allowed, but the four vertices are distinct.

For such a witness, define the three colors

\[
A=\chi_t(u,y),\qquad B=\chi_t(v,w),\qquad C=\chi_t(y,w).
\]

The one-type square aggregation records the full triple multiset

\[
Q_{1,t}(u,v)=
\multiset{(A,B,C):(y,w)\in \operatorname{Sq}_G(u,v)}.
\]

The two-type square aggregation records only

\[
Q^{\mathrm{near}}_{2,t}(u,v)=
\multiset{(A,B):(y,w)\in \operatorname{Sq}_G(u,v)}
\]

and

\[
Q^{\mathrm{opp}}_{2,t}(u,v)=
\multiset{C:(y,w)\in \operatorname{Sq}_G(u,v)}.
\]

Thus \(\square_2\) remembers the joint colors of the two edges adjacent to the
root edge, and it remembers the colors of the opposite edges, but it forgets the
correlation between those two pieces of data.

## 2. Immediate refinement

### Proposition 2.1

\[
\Delta+\square_2 \preceq \Delta+\square_1.
\]

### Proof

Fix a coloring \(\chi_t\).  For every ordered edge \((u,v)\), the one-type
square multiset

\[
\multiset{(A,B,C)}
\]

canonically determines the two two-type square multisets by projection:

\[
\multiset{(A,B,C)}\mapsto \multiset{(A,B)}
\]

and

\[
\multiset{(A,B,C)}\mapsto \multiset{C}.
\]

All other parts of the update, namely old color, incidence, and triangle terms,
are identical in the two modes.  Therefore if two ordered edges have the same
\(\Delta+\square_1\) color after a round, they also have the same
\(\Delta+\square_2\) color after that round.  Induction over rounds gives the
claim.  \(\square\)

The remaining task is strictness.

## 3. The parity core

Let the four vertex parts be

\[
U=V=W=Y=\mathbb F_2.
\]

For clarity, write the vertices as

\[
U_i,V_j,W_k,Y_\ell\qquad (i,j,k,\ell\in\mathbb F_2).
\]

The core graph has only the four cyclic complete bipartite side sets

\[
U--V,
\qquad
V--W,
\qquad
W--Y,
\qquad
Y--U.
\]

There are no edges inside a part and no diagonal side edges \(U--W\) or \(V--Y\).
Every quadruple \((i,j,k,\ell)\) gives a core 4-cycle

\[
U_i - V_j - W_k - Y_\ell - U_i.
\]

We assign a role and a bit to each core edge.  The roles are

\[
R,A,B,C,
\]

where

\[
R:U--V,
\qquad
A:U--Y,
\qquad
B:V--W,
\qquad
C:Y--W.
\]

For a parity parameter \(p\in\mathbb F_2\), define the role bits by

\[
r(U_i,V_j)=i+j,
\]

\[
a(U_i,Y_\ell)=i+\ell,
\]

\[
b(V_j,W_k)=j+k,
\]

and

\[
c_p(Y_\ell,W_k)=\ell+k+p.
\]

All sums are in \(\mathbb F_2\).  Therefore every core square
\(U_iV_jW_kY_\ell U_i\) satisfies

\[
r+a+b+c_p
=(i+j)+(i+\ell)+(j+k)+(\ell+k+p)=p.
\]

Thus the \(p=0\) core realizes the even parity distribution on the four edge
roles, and the \(p=1\) core realizes the odd parity distribution.

## 4. Removing labels with private triangles

The parity core above is easiest to describe with role/bit labels, but the
actual separating graphs are unlabelled.

Choose distinct positive integers

\[
\lambda(R,0)=1,
\quad
\lambda(R,1)=2,
\quad
\lambda(A,0)=3,
\quad
\lambda(A,1)=4,
\]

\[
\lambda(B,0)=5,
\quad
\lambda(B,1)=6,
\quad
\lambda(C,0)=7,
\quad
\lambda(C,1)=8.
\]

For each core edge \(xy\) of role/bit \(\tau=(S,b)\), attach
\(\lambda(\tau)\) private triangle vertices.  A private triangle vertex attached
to \(xy\) is adjacent exactly to \(x\) and \(y\).  The core edge \(xy\) remains.

Let \(G_p\) be the resulting ordinary unlabelled graph.

The smallest pair is

\[
G_0,G_1.
\]

Each graph has 8 core vertices.  Each of the eight role/bit types occurs on two
core edges, so the number of private vertices is

\[
2(1+2+3+4+5+6+7+8)=72.
\]

Hence

\[
|V(G_p)|=8+72=80.
\]

There are 16 core edges, and every private vertex contributes two private edges,
so

\[
|E(G_p)|=16+2\cdot 72=160.
\]

## 5. Local structure of the gadgets

We record the elementary facts used in the WL proof.

### Lemma 5.1: core triangles

A core edge of type \(\tau\) has exactly \(\lambda(\tau)\) common neighbors, and
all of them are private triangle vertices attached to that core edge.

### Proof

The core graph is 4-partite with sides only on
\(U--V,V--W,W--Y,Y--U\).  It has no core triangles.  The only vertices adjacent
to both endpoints of a core edge \(xy\) are the private vertices attached to
\(xy\).  By construction there are \(\lambda(\tau)\) of them.  \(\square\)

### Lemma 5.2: core 4-cycles

Let \(e\) be a core edge.  The simple 4-cycle witnesses of \(e\) whose root is
\(e\) are exactly the core rectangles using the other three side roles.  Private
vertices create no additional simple 4-cycle witness for a core root edge.

### Proof

Take a core root edge \((u,v)\).  A simple square witness is a pair \((y,w)\)
with edges

\[
uy,
\quad
 y w,
\quad
 wv,
\quad
vu.
\]

Since \(u,v\) are core vertices, a core rectangle always gives such a witness.
Conversely, suppose a private vertex \(q\) is used as one of \(y,w\).  The
private vertex \(q\) has only the two endpoints of its attached core edge as
neighbors.  If \(q\) is adjacent to \(u\), its other neighbor is some core vertex
\(x\).  To continue the path \(u-q-w-v-u\), the vertex \(w\) must be \(x\), but
then the required edge \(wv\) would force a core triangle or reuse a root
endpoint in a way forbidden by simplicity.  Checking the two possible positions
of \(q\) gives the same obstruction.  Thus every simple square witness of a core
edge lies entirely in the core.  \(\square\)

### Lemma 5.3: private-edge squares

Let \(q\) be a private vertex attached to a core edge \(xy\) of type \(\tau\).
For the directed private edge \((x,q)\), the simple square witnesses are exactly

\[
(q',y)
\]

where \(q'\neq q\) ranges over the other private vertices attached to \(xy\).
Thus their number and their ordered-edge type data are determined only by
\(\tau\) and by the choice of endpoint side.

### Proof

The neighbors of \(q\) are exactly \(x\) and \(y\).  In a witness for the root
\((x,q)\), the second witness vertex must be a neighbor of \(q\) different from
\(x\), hence it must be \(y\).  The first witness vertex must then be adjacent to
both \(x\) and \(y\), distinct from \(x,q,y\).  By Lemma 5.1, the common
neighbors of \(x,y\) are precisely the private vertices attached to \(xy\), and
we must exclude \(q\) itself.  This proves the claim.  \(\square\)

## 6. Why \(\Delta+\square_2\) identifies \(G_0,G_1\)

We prove a stronger typed-equitability statement.

Define the following directed edge types.

1.  A directed core type consists of a role \(S\in\{R,A,B,C\}\), a bit
    \(b\in\{0,1\}\), and an orientation along or against the displayed cyclic
    role direction.
2.  A directed private type consists of the role/bit \(\tau\) of the core edge
    to which the private vertex is attached, the endpoint side, and the
    direction core-to-private or private-to-core.

The same list of directed types exists in \(G_0\) and \(G_1\), and each type has
the same multiplicity in both graphs.

### Lemma 6.1: incidence and triangle data are type-determined

For every directed type \(\sigma\), the old type, left-incidence type multiset,
right-incidence type multiset, and triangle-pair type multiset of any directed
edge of type \(\sigma\) are independent of the parity parameter \(p\).

### Proof

Old type is part of \(\sigma\).  For incidence, observe that each core vertex in
a fixed part has exactly one incident core edge of each relevant role/bit.  For
example, a vertex \(U_i\) has one incident \(R0\) edge, one incident \(R1\) edge,
one incident \(A0\) edge, and one incident \(A1\) edge.  It is also incident to
all private edges attached to those four core edges, with multiplicities
\(\lambda(R,0),\lambda(R,1),\lambda(A,0),\lambda(A,1)\).  This description does
not depend on \(p\).  The same argument applies to parts \(V,W,Y\).  A private
vertex has degree two, and its two incident private-edge types are determined by
the type of its attached core edge.

For triangles, a core edge of type \(\tau\) has exactly \(\lambda(\tau)\) private
common neighbors by Lemma 5.1.  The two ordered private-edge types through each
such private common neighbor are determined by \(\tau\).  A private edge lies in
exactly the triangle formed by its private vertex and the attached core edge;
again the ordered types are determined by \(\tau\) and by the endpoint side.
Thus all triangle-pair type multisets are type-determined and parity-independent.
\(\square\)

### Lemma 6.2: square2 data of core edges is type-determined

For every directed core type \(\sigma\), the \(\square_2\) near-pair multiset and
opposite-edge multiset are independent of \(p\).

### Proof

It is enough to prove this for one orientation of each role; reversing all
ordered edges only replaces each directed type by its reverse.

Consider a directed \(R\)-edge \((U_i,V_j)\) with bit

\[
r=i+j.
\]

Its core square witnesses are indexed by \((k,\ell)\in\mathbb F_2^2\), giving

\[
U_i - V_j - W_k - Y_\ell - U_i.
\]

The adjacent edge bits are

\[
a=i+\ell,
\qquad
b=j+k,
\]

and the opposite edge bit is

\[
c=\ell+k+p.
\]

As \((k,
\ell)\) ranges over \(\mathbb F_2^2\), the pair \((a,b)\) ranges over all
four values of \(\mathbb F_2^2\) exactly once, independently of \(p\).  Also
\(c\) takes each value in \(\mathbb F_2\) exactly twice, independently of \(p\).
Therefore the \(\square_2\) data of the \(R_r\)-edge is parity-independent.

The same computation applies to the other roles.  Fixing one role bit in the
parity equation

\[
r+a+b+c=p
\]

leaves three free variables constrained by one affine equation.  The projection
onto any two of the three remaining variables is uniform on \(\mathbb F_2^2\),
and the projection onto the remaining single variable is uniform on
\(\mathbb F_2\).  These are exactly the near-pair and opposite-color data used by
\(\square_2\).  \(\square\)

### Lemma 6.3: square2 data of private edges is type-determined

For every directed private type \(\sigma\), the \(\square_2\) near-pair multiset
and opposite-edge multiset are independent of \(p\).

### Proof

By Lemma 5.3, the square witnesses of a private edge attached to a core edge of
type \(\tau\) use only the other private vertices attached to that same core edge
and the other endpoint of that core edge.  Hence all near and opposite directed
edge types occurring in these square witnesses are determined by \(\tau\) and by
the endpoint side of the private edge.  Since the multiplicity
\(\lambda(\tau)\) is fixed and the number of other private vertices is
\(\lambda(\tau)-1\), the square2 data is type-determined and
parity-independent.  \(\square\)

### Theorem 6.4

\[
G_0\equiv_{\Delta+\square_2}G_1.
\]

### Proof

Run \(\Delta+\square_2\) on the disjoint union \(G_0\sqcup G_1\).  We prove by
induction on the round that every directed edge type receives one common color
in both components.

At round 0 all ordered edges have the same color.  Suppose the claim holds at
round \(t\).  Then the color of a directed edge at round \(t\) is determined by
its directed type, and the interpretation of each type is the same in \(G_0\)
and \(G_1\).  Lemmas 6.1, 6.2, and 6.3 say that, after replacing each incident,
triangle, and square witness edge by its round-\(t\) type-color, the entire
\(\Delta+\square_2\) update tuple is determined by the directed type and is
parity-independent.  Therefore the round-\((t+1)\) color is again determined by
the same directed type in the same way in both graphs.

The graph-level signature is the multiset of unordered pairs of the two oriented
stable colors on each undirected edge, together with the vertex count.  Each
undirected edge type has the same multiplicity in \(G_0\) and \(G_1\), and the
stable oriented colors of that type agree across the two graphs.  The signatures
are equal.  \(\square\)

## 7. Why \(\Delta+\square_1\) separates \(G_0,G_1\)

The private triangles make the role/bit of a core edge visible before the
one-type square term is used for the parity test.

### Lemma 7.1: core role/bit visibility

After one round of \(\Delta+\square_1\), every core edge of role/bit \(\tau\) has
a directed color that determines \(\tau\).

### Proof

A core edge of type \(\tau\) lies in exactly \(\lambda(\tau)\) triangles by
Lemma 5.1.  The eight values \(\lambda(\tau)\) are distinct.  The first-round
triangle multiset therefore has a distinct cardinality for each core role/bit.
Thus the first-round color of a directed core edge determines \(\tau\).  \(\square\)

### Theorem 7.2

\[
G_0\not\equiv_{\Delta+\square_1}G_1.
\]

### Proof

Consider a core edge \((U_i,V_j)\) of role \(R\) and bit \(r=i+j\).  By Lemma
7.1, after one round the colors of the three non-root core edges in every core
square determine their role/bits \((A_a,B_b,C_c)\).

At the next round, the one-type square aggregation at \((U_i,V_j)\) contains the
full triple multiset

\[
\multiset{(A_a,B_b,C_c):a,b,c\in\mathbb F_2,
\ r+a+b+c=p}.
\]

For fixed \(r\), this is the even-parity triple set when \(p=0\) and the
odd-parity triple set when \(p=1\).  These two multisets are different, because
for example the triple \((A_0,B_0,C_r)\) occurs in exactly one of them.  The
role/bit colors \(A_0,A_1,B_0,B_1,C_0,C_1\) have already been made distinct by
the private triangle multiplicities, so no color renaming inside the disjoint
union can identify the two triple multisets.

Therefore a core \(R_r\)-edge in \(G_0\) receives a different
\(\Delta+\square_1\) color from a core \(R_r\)-edge in \(G_1\).  Since each graph
has core \(R_r\)-edges and these edge colors appear in the graph-level edge
signature, the graph signatures differ.  \(\square\)

---

## 8. Final conclusion

Combining Proposition 2.1, Theorem 6.4, and Theorem 7.2 gives

\[
\boxed{\Delta+\square_2 \prec \Delta+\square_1.}
\]

Together with the previously proved odd-cycle separation from full 2-WL, the
edge-motif hierarchy now contains the strict chain

\[
\boxed{
\Delta+\square_2
\prec
\Delta+\square_1
\prec
2\mathrm{WL}.
}
\]

The first strictness is witnessed by the parity-square pair \(G_0,G_1\).  The
second strictness is witnessed by

\[
C_5\sqcup C_5
\quad\text{and}\quad
C_{10}.
\]
